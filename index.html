How Incompatibility Rules Work

Sometimes two traits overlap awkwardly when combined randomly (for example, a bulky helmet covering up sunglasses). Add a rule below to prevent conflicting traits from ever appearing together on the same NFT.

Example 1: Eyewear Clash

IF 03_Eyewear = Pirate Eyepatch
DO NOT ALLOW 03_Eyewear = Red Bolt Shades

Example 2: Headgear vs Halo

IF 04_Headgear = King Gold Crown
DO NOT ALLOW 04_Headgear = Lightning Halo

Example 3: Layer Exclusion

IF 02_Outfit = Any trait (or one specific trait)
SKIP LAYERS 04_Headgear, 03_Eyewear (never drawn at all)
